# جدولي | JADWALI

تطبيق ويب (PWA) للجدول الأسبوعي لطلاب الصف الثاني المتوسط، الفصل 5/2، مدرسة الليث بن سعد.

## الملفات
- `index.html`: التطبيق كاملاً (HTML وCSS وJavaScript).
- `manifest.webmanifest` و`service-worker.js` و`icons/`: التثبيت والعمل دون اتصال.
- `firestore.rules`: قواعد الأمان المقترحة.

## 1. إعدادات Firebase
إعدادات مشروع `jadwali-93760` موضوعة مسبقاً في الكائن `firebaseConfig` أعلى سكربت `index.html`. لم أستخدم Analytics عمداً.

## 2. Authentication
- فعّل مزود Email/Password.
- في Authentication > Settings > Authorized domains أضف نطاق الاستضافة الذي ستنشر عليه.
- حساب المدير موجود مسبقاً (UID: `YdkQgSqZ0rPd1QV081Zg3E7TRIA3`). أي حساب آخر يُسجَّل خروجه تلقائياً.

## 3. قواعد Firestore (مهم)
أنت ذكرت أن القواعد الحالية تسمح بالقراءة للجميع والكتابة للمدير. التطبيق يكتب في ثلاثة مسارات:
`schedules/current` و`archives/{id}` و`drafts/current`. إن لم تكن القواعد الحالية تغطي `drafts` فانسخ محتوى `firestore.rules` ولصقه في Firestore > Rules ثم Publish. أهم ما يضيفه الملف:
- `drafts` للمدير فقط (قراءة وكتابة).
- `archives` قراءة للجميع وإنشاء للمدير فقط، دون تعديل أو حذف، فلا يستطيع أحد تغيير الأرشيف.

إن لم تُسمح `drafts`، تبقى المسودة محفوظة تلقائياً على جهاز المدير ويُنبَّه إلى ذلك في اللوحة.

## 4. النشر
أي استضافة HTTPS تصلح (مطلوب لـ PWA). مع Firebase Hosting:
```
npm i -g firebase-tools
firebase login
firebase deploy --only hosting   # firebase.json و.firebaserc جاهزان داخل المجلد
```
افتح الرابط على Android بـ Chrome ثم «تثبيت التطبيق».

## 5. طريقة الاستخدام
- الطلاب: يفتحون الرابط فيرون آخر جدول منشور، ويتحدث تلقائياً عند نشر جدول جديد.
- المدير: الإعدادات > دخول المدير > لوحة الإدارة. حرّر المواد، عاين، ثم «نشر الجدول». يُؤرشف الجدول السابق تلقائياً في العملية نفسها (دفعة واحدة).
- أوقات الحصص اختيارية من اللوحة؛ ولا يُميَّز «الحصة الحالية» إلا بعد إضافتها.

## 6. تحديث التطبيق
عند تعديل الملفات غيّر `VERSION` في `service-worker.js` (مثلاً `jadwali-v2`) ثم انشر. يتحدث التطبيق عند فتحه التالي.

## ملاحظات
- لا توجد إشعارات من أي نوع.
- لا يوجد OTP: التحقق الإضافي عبر البريد يحتاج Cloud Functions ومزود بريد، ويُضاف لاحقاً.
- الحماية الفعلية في قواعد Firestore وليست في إخفاء الأزرار.
